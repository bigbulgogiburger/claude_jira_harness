# jira-test — 스택별 통합 테스트 실행

코드 변경사항에 대한 테스트를 스택에 맞게 자동 실행하고 결과를 검증합니다.
지라에 댓글이나 설명을 작성할 때에는 한글로 작성합니다.

## Usage

```
/jira-test [test-scope]
```

- `test-scope` (선택): `unit`, `lint`, `build`, `all` (기본값: `all`)

## Procedure

### 1. 스택 감지

작업 디렉토리에서 프로젝트 스택을 자동 감지합니다.
감지 기준은 `jira-start` 스킬과 동일합니다.

### 2. 스택별 테스트 실행

감지된 스택에 따라 적절한 테스트 명령을 실행합니다.
각 스택의 상세 테스트 패턴은 `references/` 디렉토리를 참조합니다.

#### 공통 구조

모든 스택에서 다음 3가지 카테고리의 테스트를 수행합니다:

| 카테고리 | 설명 |
|----------|------|
| Lint/Analyze | 코드 스타일 및 정적 분석 |
| Test | 단위/통합 테스트 |
| Build | 프로덕션 빌드 검증 |

### 3. 결과 출력

```
🧪 테스트 실행 중... (스택: <감지된 스택>)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ Lint/Analyze:    통과
✅ Test:            통과 (X passed, 0 failed)
✅ Build:           성공

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

다음 단계: /jira-commit으로 변경사항 커밋
```

## Quality Gates

모든 테스트가 통과해야 다음 단계로 진행 가능:
- ✅ Lint/Analyze 오류 0개
- ✅ 테스트 실패 0개
- ✅ 빌드 성공

## Error Handling

- 테스트 실패 시 상세 오류 메시지 출력
- 각 단계별 실패 시 즉시 중단하고 수정 안내
- CLAUDE.md에 커스텀 테스트 명령이 정의되어 있으면 우선 사용

## Notes

- CLAUDE.md에 프로젝트별 테스트 명령이 정의되어 있으면 해당 명령을 우선 사용
- 테스트 실패 시 커밋하지 말 것
